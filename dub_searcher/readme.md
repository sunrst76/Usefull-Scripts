# 🔍 Интерактивный поиск и удаление дубликатов файлов (dashboard.ps1)

Профессиональный консольный скрипт автоматизации на языке **PowerShell** для сканирования каталогов, обнаружения идентичных файлов-дубликатов по их контрольным суммам и их интерактивного удаления для освобождения дискового пространства.

## ✨ Ключевые возможности (Features)

* 📁 **Удобный графический выбор папки**: использует WinForms-диалог (`FolderBrowserDialog`), позволяя пользователю комфортно выбрать целевую директорию для сканирования через стандартное окно Windows.
* 🖥️ **Win32 API Интеграция**: автоматически вызывает функции `user32.dll` (`SetForegroundWindow`, `ShowWindow`), чтобы окно консоли гарантированно выходило на передний план для пользователя при старте.
* 🧮 **Точный криптографический анализ**:
  * Фильтрует файлы по размеру, отсекая пустые документы.
  * Вычисляет хэш-суммы файлов по алгоритму **SHA256** для гарантированного поиска 100% копий (даже если у них совершенно разные имена).
* 📊 **Интеллектуальная группировка и фильтрация**: автоматически собирает дубликаты в группы и выводит на экран только те файлы, у которых найдены реальные копии в системе.
* 🗑️ **Гибкое интерактивное меню удаления**:
  * Выводит пронумерованные списки найденных дубликатов с указанием их путей.
  * Предоставляет пользователю выбор: удалить **все** копии, оставить **первый** найденный файл, оставить **последний** или завершить работу программы.
* 🎨 **Цветовая индикация и логирование**: каждый этап работы (сканирование, вычисление хэшей, обнаружение совпадений, удаление) сопровождается понятными логами с цветовой индикацией статусов.

## 🛠️ Стек технологий (Tech Stack)

* **Язык**: PowerShell 5.1+ / PowerShell 7+
* **Технологии**: .NET Framework (WinForms), Win32 API Interop, Командлет `Get-FileHash` (алгоритм SHA256).
* **ОС**: Windows 10 / 11.

## 🚀 Инструкция по запуску

Скрипт полностью автономен и не требует сторонних модулей. Для сканирования системных каталогов рекомендуется запускать PowerShell от имени Администратора.

1. Откройте терминал в папке проекта.
2. Перед первым запуском (если в системе заблокированы скрипты) выполните команду:
```
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
```
3. Запустите утилиту:
   ```powershell
   .\dashboard.ps1
   ```
или запустите с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.

4. В открывшемся окне выберите папку для проверки и следуйте пошаговым инструкциям в консоли.
