# 📊 Системный дашборд администратора (Dashboard.ps1)

Интерактивный консольный дашборд на языке **PowerShell**, предназначенный для мониторинга состояния операционной системы, управления процессами и быстрой диагностики Windows-серверов или рабочих станций.

## ✨ Ключевые возможности (Features)

* 🖥️ **Мониторинг ресурсов в реальном времени**:
  * Вывод информации о загрузке процессора (CPU) и оперативной памяти (RAM).
  * Анализ свободного места на жестких дисках и локальных разделах.
* ⚙️ **Управление процессами и службами**:
  * Интерактивный просмотр списка запущенных процессов.
  * Возможность быстрого поиска, фильтрации и принудительного завершения зависших задач.
  * Мониторинг статуса критически важных системных служб (Services).
* 🌐 **Сетевая диагностика**: быстрый доступ к проверке сетевых интерфейсов, текущих подключений и пингу удаленных узлов.
* 🎨 **Текстовый псевдоинтерфейс (TUI)**: удобное структурированное меню с цветовым разделением блоков информации и динамическим обновлением экрана.
* ⌨️ **Удобная навигация**: интуитивно понятное управление через ввод цифровых команд для переключения между экранами и модулями.

## 🛠️ Стек технологий (Tech Stack)

* **Язык**: PowerShell 5.1+ / PowerShell 7+
* **Командлеты**: Использование встроенного инструментария WMI/CIM (`Get-CimInstance`, `Get-Process`, `Get-Service`).
* **Платформа**: Windows 10 / 11, Windows Server.

## 🚀 Инструкция по запуску

Для получения полной информации о некоторых системных процессах и службах скрипт настоятельно рекомендуется запускать от имени **Администратора**.

1. Откройте PowerShell в папке проекта `/dashboard`.
2. Перед первым запуском (если в системе заблокированы скрипты) выполните команду:
```
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
```
3. Запустите дашборд:
   ```powershell
   .\dashboard.ps1
   ```
   или запустите с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
4. Используйте главное меню для выбора интересующего вас раздела мониторинга.
