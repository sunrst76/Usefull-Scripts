### 📋 Генератор технического отчета ПК (PC_Specification_Report.ps1)

Интерактивный PowerShell-скрипт, предназначенный для глубокого аудита системы, автоматического сбора технических характеристик компьютера и создания структурированного, визуально приятного отчета в форматах HTML и PDF.

### 🧩 Ключевые возможности (Features)

* **💻 Глубокий аудит аппаратной части (Hardware):** 

  * Сбор подробных данных о процессоре (CPU) с указанием физических ядер, потоков и текущей частоты.
  * Анализ оперативной памяти (RAM) с подсчетом общего объема и количества установленных модулей.
  * Сканирование дисковых накопителей с определением их моделей и емкости в ГБ.
  * Определение видеокарты (GPU), версии видеодрайвера и текущего разрешения экрана.
* **⚙️ Мониторинг операционной системы и платформ:** 

  * Вывод точной версии Windows, её архитектуры (x64/x86) и системных каталогов.
  * Определение производителя и точной модели материнской платы.
* **🌐 Сетевой аудит:** сканирование активных сетевых интерфейсов, их имен и физических MAC-адресов.
* **🎨 Интерактивный интерфейс и экспорт:** 

  * Графический GUI-выбор пути сохранения файла через системный SaveFileDialog.
  * Выбор формата на выходе: генерация адаптивной веб-страницы (HTML) или автоматическая фоновая конвертация в документ (PDF) через движок Microsoft Edge.
* **🛡️ Отказоустойчивость:** изоляция блоков WMI/CIM-запросов через try-catch для гарантированного завершения работы скрипта даже при сбоях отдельных датчиков.

### 🛠️ Стек технологий (Tech Stack)

* **Язык:** PowerShell 5.1+ / PowerShell 7+
* **Командлеты:** WMI/CIM инструменты (Get-CimInstance), компоненты .NET/Windows Forms.
* **Платформа:** Windows 10 / 11, Windows Server.

### 🚀 Инструкция по запуску

Для получения полной информации обо всех компонентах (особенно о модулях RAM) скрипт настоятельно рекомендуется запускать **от имени Администратора**. 

1. Откройте PowerShell в папке со скриптом.
2. Перед первым запуском (если в системе заблокированы скрипты) выполните команду:

powershell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

Используйте код с осторожностью.

3. Запустите скрипт генерации отчета:

powershell

.\PC_Specification_Report.ps1

Используйте код с осторожностью.
  ```
4. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
   ```
5. В открывшемся графическом окне выберите папку для сохранения, а затем в консоли укажите желаемый формат файла (1 для HTML, 2 для PDF).
