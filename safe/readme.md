### 🔐 Утилита шифрования файлов (safe.ps1)

Графическая утилита на языке PowerShell (Windows Forms), предназначенная для надежной защиты конфиденциальных данных. Скрипт позволяет шифровать и дешифровать файлы любого формата с использованием криптографических алгоритмов AES (Rijndael) и RC2, поддерживая генерацию ключей на основе пароля и безопасное удаление исходников. 

 
### 🧩 Ключевые возможности (Features)

* **🖥️ Полноценный графический интерфейс (GUI):** 

  * Интуитивное окно на базе Windows Forms с удобным расположением элементов.
  * Текстовые поля для ввода пароля (со скрытием символов) и отображения путей к файлам.
  * Интерактивные переключатели (RadioButtons) для выбора алгоритма и режима работы.
* **🛡️ Надежные алгоритмы шифрования:** 

  * **AES (Rijndael):** современный стандарт симметричного шифрования с высокой степенью стойкости.
  * **RC2:** классический блочный шифр для специфических сценариев совместимости.
* **🔑 Безопасная генерация ключей:** 

  * Использование класса Rfc2898DeriveBytes (PBKDF2) для создания надежного криптографического ключа и вектора инициализации (IV) на основе пользовательского пароля и случайной соли.
* **⚙️ Продвинутые режимы обработки:** 

  * Автоматическое создание безопасных резервных копий при обработке.
  * Опция **"Удалить файл после завершения"** для безвозвратного уничтожения исходного незашифрованного документа.
  * Корректная обработка потоков данных через CryptoStream блоками по 4 КБ для стабильной работы с файлами большого объема.

### 🛠️ Стек технологий (Tech Stack)

* **Язык:** PowerShell 5.1+ / PowerShell 7+
* **Интерфейс:** .NET Windows Forms (System.Windows.Forms, System.Drawing).
* **Криптография:** .NET Security (System.Security.Cryptography).
* **Платформа:** Windows 10 / 11, Windows Server.

### 🚀 Инструкция по запуску

Скрипт полностью автономен и не требует установки сторонних библиотек. 

1. Откройте PowerShell в папке со скриптом.
2. Перед первым запуском (если в системе заблокированы скрипты) выполните команду:

powershell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

Используйте код с осторожностью.

3. Запустите утилиту:

powershell

.\safe.ps1

Используйте код с осторожностью.
```
4. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
   ```

5. В открывшемся окне выберите файл, укажите алгоритм, введите пароль и нажмите кнопку для выполнения операции.
