### 🔍 Многофункциональный поисковик файлов (searcher.ps1)

Графическая утилита на языке PowerShell (Windows Forms), разработанная для глубокого, быстрого и гибкого поиска файлов, а также текстового содержимого внутри них. Скрипт предоставляет продвинутые фильтры и удобный интерфейс, заменяющий стандартный и часто медленный поиск Windows.

### 🧩 Ключевые возможности (Features)

* **🖥️ Графический интерфейс пользователя (GUI):** 

  * Полноценное интерактивное окно на базе Windows Forms для настройки параметров поиска.
  * Удобные текстовые поля для указания целевой папки, маски файла и искомого текста.
  * Выпадающие списки и флажки для быстрой активации расширенных фильтров.
* **🔎 Глубокий поиск контента (Grep-функционал):** 

  * Поиск конкретных строк или текстовых паттернов внутри файлов.
  * Поддержка **регулярных выражений (RegEx)** для поиска сложных текстовых совпадений.
  * Возможность включения/выключения учета регистра символов (Case Sensitivity).
* **📅 Продвинутая фильтрация файлов:** 

  * **По размеру:** ограничение результатов файлами «больше чем» или «меньше чем» заданный объем (КБ/МБ/ГБ).
  * **По дате:** фильтрация документов по времени их создания или последней модификации.
  * **По расширению:** использование масок (например, *.txt, *.log, *.docx) для сканирования конкретных типов данных.
* **📊 Обработка и экспорт результатов:** 

  * Вывод найденных файлов в виде интерактивной таблицы (GridView) или списка внутри интерфейса.
  * Возможность быстрого экспорта сформированного отчета с результатами в формат CSV или текстовый лог.
  * Корректная обработка ошибок доступа к защищенным системным папкам (try-catch), предотвращающая зависание или падение утилиты.

### 🛠️ Стек технологий (Tech Stack)

* **Язык:** PowerShell 5.1+ / PowerShell 7+
* **Интерфейс:** .NET Windows Forms (System.Windows.Forms, System.Drawing).
* **Компоненты поиска:** Комбинация команд поиска файлов (Get-ChildItem) и чтения контента (Select-String / .NET StreamReader).
* **Платформа:** Windows 10 / 11, Windows Server.

### 🚀 Инструкция по запуску

Для корректного сканирования системных директорий и скрытых папок скрипт рекомендуется запускать **от имени Администратора**. 

1. Откройте PowerShell в папке со скриптом.
2. Перед первым запуском (если в системе заблокированы скрипты) выполните команду:

powershell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

Используйте код с осторожностью.

3. Запустите утилиту:

powershell

.\searcher.ps1

Используйте код с осторожностью.
```
4. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
   ```

5. В открывшемся окне укажите путь к папке для сканирования, задайте критерии (текст, размер или дату) и нажмите кнопку запуска поиска.
