# 💾 Диагностика накопителей и SMART-мониторинг (DiskHealthChecker.ps1)

Консольный скрипт автоматизации на языке **PowerShell** для экспресс-проверки здоровья, сбора технических характеристик и глубокого SMART-анализа физических дисков (HDD, SSD, NVMe), установленных в системе.

## ✨ Ключевые возможности (Features)

* 📊 **Сбор базовой информации о дисках**:
  * Определение порядкового номера устройства (`DeviceID`) и его коммерческого названия.
  * Распознавание типа носителя (`Media Type`: SSD/HDD/Unspecified) и типа подключения (`OperationalStatus`).
  * Автоматический пересчет и округление емкости диска в Гигабайты (ГБ).
* 🩺 **Интеллектуальная оценка здоровья**: базовый опрос состояния накопителя с мгновенной цветовой индикацией (`Green` — полностью исправен, `Red` — обнаружены проблемы).
* 🔍 **Глубокая SMART-диагностика (для SSD/NVMe)**:
  * **Остаток ресурса (Wear Level)**: считывание процента износа ячеек памяти и вычисление оставшегося срока службы накопителя (с подсветкой критического порога износа менее 20%).
  * **Мониторинг температуры**: вывод текущих температурных показателей встроенного датчика с предупреждением о перегреве (желтый цвет при >50°C, красный — при опасных >65°C).
  * **Анализ ошибок**: проверка аппаратного счетчика критических предупреждений и ошибок чтения данных (`ReadErrorsTotal`).
* 🛡️ **Отказоустойчивость**: встроенная обработка исключений (блок `try-catch`) для старых моделей HDD, которые не поддерживают расширенные командлеты надежности хранения.

## 🛠️ Стек технологий (Tech Stack)

* **Язык**: PowerShell 5.1+ / PowerShell 7+
* **Командлеты**: Использование встроенного системного модуля `Storage` (`Get-PhysicalDisk`, `Get-StorageReliabilityCounter`).
* **Платформа**: Windows 10 / 11, Windows Server.

## 🚀 Инструкция по запуску

⚠️ **Важно:** Для опроса низкоуровневых счетчиков надежности железа и работы с командлетами Storage скрипт необходимо запускать строго **от имени Администратора**. В противном случае Windows заблокирует доступ к оборудованию.

1. Откройте Windows Terminal или PowerShell от имени Администратора.
2. Перейдите в папку со скриптом и запустите его:
   ```powershell
   .\DiskHealthChecker.ps1
   ```
3. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
   ```
4. Дождитесь окончания сбора информации. Для выхода из утилиты нажмите любую клавишу в окне консоли.
