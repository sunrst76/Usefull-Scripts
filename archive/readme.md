# 📦 Модуль резервного копирования и архивации (Archive.ps1)

Скрипт автоматизации на языке **PowerShell** для быстрого, выборочного резервного копирования файлов и папок. Утилита позволяет гибко собирать данные из разных источников и сохранять их в сжатые ZIP-архивы.

## ✨ Ключевые возможности (Features)

* 🗂️ **Мульти-источники (Multi-source Backup)**: возможность одновременного выбора и объединения файлов и изолированных папок из совершенно разных директорий компьютера в один архив.
* 🔄 **Два режима работы с архивами**:
  * **Создание нового архива**: упаковка выбранных данных в новый сжатый `.zip` файл.
  * **Дозапись в существующий архив**: умное добавление новых файлов в уже созданный ранее архив без его полной перезаписи.
* 📊 **Информативное логирование**: интерактивный консольный вывод с цветовой индикацией статуса работы (зеленый — для успешных операций, красный — для ошибок, желтый — для предупреждений).
* 🛡️ **Отказоустойчивость**: встроенная обработка исключений (блок `try-catch`) при ошибках доступа к защищенным системным файлам или заблокированным процессами документам.
* ↩️ **Интерактивное меню**: пошаговый консольный интерфейс, запрашивающий пути, имена файлов и подтверждения действий у пользователя.

## 🛠️ Стек технологий (Tech Stack)

* **Язык**: PowerShell 5.1+ / PowerShell 7+
* **Модули**: Встроенные средства работы с файловой системой и архивацией (`Compress-Archive`).
* **Платформа**: Windows 10 / 11.

## 🚀 Инструкция по запуску

Для работы со скриптом не требуются права администратора, если вы копируете файлы своего пользователя. Однако для бэкапа системных папок (например, `Program Files`) запустите консоль от имени Администратора.

1. Откройте PowerShell в папке проекта `/archive`.
2. Перед первым запуском (если в системе заблокированы скрипты) выполните команду:
   ```
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
   ```
3. Выполните запуск утилиты:
   ```powershell
   .\Archive.ps1
   ```
   или запустите с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
4. Следуйте текстовым подсказкам в консоли для выбора папок-источников и указания пути к итоговому ZIP-файлу.
