### 🧹 Быстрая очистка временных файлов (temp_eraser.ps1)

Легковесный PowerShell-скрипт для автоматического освобождения дискового пространства путем удаления временных файлов, кэша операционной системы и принудительной очистки системной корзины Windows.

### 🧩 Ключевые возможности (Features)

* **📂 Комплексная очистка кэша ОС:** 

  * Сканирование и очистка папки временных файлов текущего пользователя (GetTempPath).
  * Полная очистка системной папки временных файлов Windows (C:\Windows\Temp).
  * Удаление содержимого директории Prefetch для оптимизации и удаления устаревших данных запуска программ.
* **⚡ Принудительное удаление без лишних вопросов:** 

  * Использование встроенных консольных утилит для принудительного удаления файлов, включая скрытые и системные объекты (del /f /q /a).
  * Рекурсивное удаление всех подпапок и каталогов любой вложенности, включая папки со специфическими GUID-именами (rmdir /s /q).
  * Подавление лишнего вывода ошибок командной строки для чистой индикации в процессе работы.
* **🗑️ Автоматическая очистка корзины:** 

  * Интеграция с командлетом Clear-RecycleBin для полной очистки корзины во всех разделах (актуально для Windows 10/11).
  * Встроенная обработка исключений try-catch, предотвращающая остановку скрипта, если корзина уже пуста или недоступна.
* **🎨 Информативный UI:** цветовое разделение этапов очистки (выделение текущих папок желтым, успешных статусов зеленым и заголовков голубым цветом).

### 🛠️ Стек технологий (Tech Stack)

* **Язык:** PowerShell 5.1+ / PowerShell 7+
* **Командлеты и вызовы:** Test-Path, Clear-RecycleBin, прямые вызовы командного интерпретатора cmd.exe.
* **Платформа:** Windows 10 / 11, Windows Server.

### 🚀 Инструкция по запуску

Для очистки системных директорий (таких как Temp и Prefetch в каталоге Windows) скрипт **необходимо запускать от имени Администратора**. 

1. Откройте PowerShell от имени Администратора.
2. Перед первым запуском (если в системе заблокировано выполнение скриптов) выполните:

powershell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

Используйте код с осторожностью.

3. Перейдите в папку со скриптом и запустите его:

powershell

.\temp_eraser.ps1

Используйте код с осторожностью.
```
4. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
   ```

5. Дождитесь уведомления === Очистка завершена! === и нажмите любую клавишу для закрытия консоли.
