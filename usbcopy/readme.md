### 🔄 Комплексная система синхронизации и установки обновлений (Update Synchronization Suite)

Набор кроссплатформенных автоматизированных сценариев (PowerShell, Bash, CMD) для быстрой, безопасной и контролируемой синхронизации файлов обновлений ПО между локальными хранилищами, съемными носителями (флешками) и целевыми серверами. Система поддерживает полностью автоматический запуск задач при подключении накопителя. 

### 🧩 Ключевые возможности (Features)

* **🔌 Автоматический триггер по событию (watcher.ps1):** 

  * Постоянный фоновый мониторинг наличия целевого диска (D:\) с интервалом опроса в 2 секунды.
  * Умное отслеживание состояния монтирования флешки с автоматическим сбросом флагов при её извлечении ($IsMounted = $false).
  * Автоматический запуск синхронизации антивирусных баз (ТСПР и АПК) через дочерние процессы Start-Process сразу после обнаружения диска.
  * Встроенная валидация путей (Test-Path) перед вызовом исполняемых файлов с выводом предупреждений.
* **🐧 Bash-модуль синхронизации (Linux):** 

  * Скрипт copy_updates.sh для автоматического обнаружения точек монтирования (/run/user/.../media).
  * Высокоскоростное фоновое копирование данных с помощью утилиты cp -ruv с логированием во временные файлы.
  * Текстовый индикатор прогресса (Progress Bar) реального времени со счетчиком обработанных данных и защитой от деления на ноль.
* **🪟 PowerShell-модули автоматизации (Windows):** 

  * **Продвинутая репликация через Robocopy (Updates_Copy_alternate.ps1):** использование системной утилиты Robocopy в режиме зеркалирования (/MIR), многопоточности (/MT:24) и автоматического парсинга консольного вывода для отрисовки графического индикатора Write-Progress.
  * **Кастомная пофайловая синхронизация (UpdatesCopy.ps1 / Updates_linuxCopy.ps1):** алгоритмы глубокого побайтового сравнения, анализа хэш-сумм и метаданных файлов (LastWriteTime, Length), автоматическое воссоздание структуры пустых папок и расчет точного времени до окончания операции (ETA).
* **🧪 Автоматическое тестирование (Pester Tests):** 

  * Тестовый скрипт Updates_Copy_alternate.Tests.ps1 на базе фреймворка Pester для изолированного тестирования логики.
  * Использование изолированных временных папок-заглушек (MockSourceFolder / MockDestFolder) и генераторов тестовых файлов различных форматов (.txt, .log, .bin) для проверки граничных условий и отказоустойчивости.
* ** оболочки (.cmd):** 

  * Набор лаунчеров (UpdatesCopy.cmd, Updates_linuxCopy.cmd и др.) с принудительной установкой кодировки UTF-8 (chcp 65001), настройкой геометрии окна консоли (mode con:) и обходом политики выполнения сценариев PowerShell (-ExecutionPolicy Bypass).
* **🎨 Информативные TUI-интерфейсы:** полное цветовое кодирование этапов выполнения (Cyan — прогресс и статус вотчера, Yellow — запуск синхронизации, Green — успешное подключение, Red — извлечение флешки или критические ошибки путей).

### 🛠️ Стек технологий (Tech Stack)

* **Linux OS:** GNU Bash, find, wc, sleep, kill.
* **Windows OS:** PowerShell 5.1+ / 7+, .NET Framework (System.Collections.Generic.List[string]), командлеты Get-ChildItem, Test-Path, New-Item, Start-Process.
* **Тестирование:** Pester Framework v5.
* **Утилиты копирования:** Microsoft Robocopy, стандартный cp.

### 📂 Структура репозитория

```text

├── watcher.ps1                      # Скрипт автоматического мониторинга подключения диска D:\
├── copy_updates.sh                  # Основной скрипт синхронизации для Linux (Bash)
├── UpdatesCopy.ps1                  # Пофайловый менеджер обновлений (Windows)
├── Updates_linuxCopy.ps1            # Скрипт пофайловой синхронизации под Linux-структуру
├── Updates_Copy_alternate.ps1       # Высокоскоростной скрипт на базе Robocopy
├── Updates_Copy_alternate.Tests.ps1 # Модульные Pester-тесты для валидации логики
├── UpdatesCopy.cmd                  # CMD-запускник для пофайлового скрипта
├── Updates_linuxCopy.cmd            # CMD-запускник для Linux-ориентированной копии
├── Updates_linuxCopy_alternate.cmd  # CMD-запускник для автоматизации через Robocopy под Linux
└── Updates_Copy_alternate.cmd       # Базовый CMD-запускник альтернативного сценария
```
Используйте код с осторожностью.

### 🚀 Инструкция по запуску

### Режим полной автоматизации (Windows):

Чтобы система сама реагировала на вставленную флешку и обновляла базы, запустите диспетчер событий: 

powershell

.\watcher.ps1

Используйте код с осторожностью.

Скрипт перейдет в режим ожидания. Как только в системе появится диск D:\, он самостоятельно активирует скрипты Updates_linuxCopy_alternate.cmd и Updates_Copy_alternate.cmd. 

### Запуск в среде Linux:

1. Перейдите в каталог со скриптом и выдайте права на исполнение: 

bash

chmod +x copy_updates.sh

Используйте код с осторожностью.
2. Запустите выполнение: 

bash

./copy_updates.sh

Используйте код с осторожностью.

3. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
