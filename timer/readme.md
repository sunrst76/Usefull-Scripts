### ⏰ Менеджер напоминаний и задач (timer.ps1)

Многофункциональный органайзер с графическим интерфейсом (GUI) на PowerShell, предназначенный для создания, отслеживания и управления периодическими или разовыми напоминаниями. Скрипт работает в фоновом режиме, сворачивается в системный трей и выводит интерактивные карточки задач поверх всех окон.

### 🧩 Ключевые возможности (Features)

* **🖥️ Развитый графический интерфейс (GUI):** 

  * Главное окно на Windows Forms для просмотра списка активных задач, добавления новых напоминаний и удаления старых.
  * Интерактивные всплывающие подсказки при наведении курсора на элементы списка.
  * Использование стандартных элементов управления: календарей (DateTimePicker), списков и текстовых полей.
* **🔄 Гибкая система повторений (Recurrence):** 

  * Поддержка различных типов повторов: по минутам, ежедневно, еженедельно или без повтора.
  * Умный математический расчет следующего времени срабатывания с защитой от накопления «мертвых» прошлых задач (автоматический сдвиг на актуальное время).
* **📦 Энергонезависимое хранение данных:** 

  * Автоматическое сохранение базы данных напоминаний в текстовый файл powershell_reminders.json в профиле пользователя.
  * Автоматическое исправление структуры базы данных при обнаружении поврежденных или пустых записей во время запуска.
* **📥 Фоновый режим и интеграция с системой:** 

  * Жесткая защита от дубликатов: при повторном запуске скрипт автоматически находит и завершает свои старые фоновые процессы.
  * Поддержка системного трея Windows (NotifyIcon) с контекстным меню для быстрого разворачивания программы или полного выхода из планировщика.
  * Скрытие консольного окна PowerShell при переходе в режим мониторинга.
* **🔔 Интерактивные карточки уведомлений:** 

  * При срабатывании таймера в углу экрана появляется кастомное анимированное окно уведомления.
  * Звуковое сопровождение событий с помощью стандартных системных звуков Windows.
  * **Функция «Перенести»:** возможность отложить сработавшую задачу на определенное количество минут или на другую выбранную дату прямо из карточки.
  * **Функция «Понятно»:** автоматический перевод циклической задачи на следующий круг или ее деактивация.

### 🛠️ Стек технологий (Tech Stack)

* **Язык:** PowerShell 5.1+ / PowerShell 7+
* **Интерфейс:** .NET Framework (System.Windows.Forms, System.Drawing).
* **Системные вызовы:** Windows API через Add-Type (управление видимостью окон, фоновые потоки).
* **Формат данных:** JSON (ConvertFrom-Json, ConvertTo-Json).

### 🚀 Инструкция по запуску

Скрипт автономен и не требует развертывания дополнительных баз данных. 

1. Откройте PowerShell в папке со скриптом.
2. Разрешите запуск сценариев (если требуется):

powershell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

Используйте код с осторожностью.

3. Запустите менеджер:

powershell

.\timer.ps1

Используйте код с осторожностью.
5. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.

6. Также можно ярлык поместить в автозагрузку пользователя. Для этого:

поместите ярлык в автозагрузку текущего пользователя:
нажмите Win+R, в открывшемся окне введите shell:startup и нажмите Enter
скопируйте ярлык скрипта в открывшуюся папку и перезагрузите компьютер

7. Программа откроет графический интерфейс. Задайте текст напоминания, выберите периодичность и нажмите кнопку добавления. Кнопка «Свернуть в трей» переведет утилиту в режим фонового мониторинга.
