### ⏳ Умное автовыключение ПК (smart_shutdown.ps1)

Интерактивный PowerShell-скрипт для автоматического завершения работы операционной системы Windows по окончании выполнения определенной программы или процесса. Идеально подходит для сценариев, когда нужно оставить ПК включенным для долгого рендеринга, скачивания тяжелых файлов или выполнения долгих вычислений, и автоматически выключить его по завершении задачи.

### 🧩 Ключевые возможности (Features)

* **🔍 Интерактивный поиск и фильтрация задач:** 

  * Удобный поиск по ключевым словам для быстрого нахождения нужной программы среди сотен запущенных процессов.
  * Возможность отображения полного списка всех активных процессов в системе при пустом вводе.
* **📦 Умная группировка дубликатов:** 

  * Автоматическое объединение одноименных процессов (например, множества вкладок Chrome, Edge или системных подпроцессов svchost) в один пункт меню.
  * Наглядное отображение количества запущенных копий приложения в оперативной памяти (например, [Копий в памяти: 5]).
* **📋 Информативное консольное меню:** 

  * Генерация динамического пронумерованного списка (меню выбора по ID) с подгрузкой официальных описаний для каждого приложения, если они доступны.
* **📡 Фоновый радар-мониторинг:** 

  * Циклический опрос состояния выбранного процесса каждые 20 секунд, обеспечивающий минимальную и незаметную нагрузку на центральный процессор.
* **🛡️ Безопасное выключение с таймером отмены:** 

  * При завершении целевой программы скрипт запускает системный таймер выключения Windows на 60 секунд.
  * У пользователя остается ровно одна минута, чтобы отменить автоматическое выключение командой shutdown /a, если это произошло случайно.

### 🛠️ Стек технологий (Tech Stack)

* **Язык:** PowerShell 5.1+ / PowerShell 7+
* **Командлеты:** Работа с процессами (Get-Process, Group-Object), системные вызовы Windows API (shutdown.exe).
* **Платформа:** Windows 10 / 11, Windows Server.

### 🚀 Инструкция по запуску

Скрипт полностью автономен, написан на чистом PowerShell и не требует установки внешних зависимостей. 

1. Откройте консоль PowerShell.
2. Перед первым запуском (если в системе заблокировано выполнение скриптов) выполните:

powershell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

Используйте код с осторожностью.

3. Запустите скрипт автовыключения:

powershell

.\smart_shutdown.ps1

Используйте код с осторожностью.
```
4. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
   ```

5. **Как пользоваться:** 

  * Введите название программы (или нажмите *Enter* для вывода всех процессов).
  * Введите порядковый цифровой **ID** процесса из сгенерированной таблицы.
  * Оставьте окно консоли открытым — скрипт начнет отслеживание. Для ручной отмены просто закройте окно PowerShell.
