### 🔌 Анализатор серийных номеров USB-устройств (usbserial.ps1)

Специализированный PowerShell-скрипт для системных администраторов и инженеров, предназначенный для сканирования подключенных USB-накопителей и COM-устройств. Скрипт выполняет глубокий аудит реестра Windows для автоматического сопоставления физических USB-портов, серийных номеров оборудования, идентификаторов производителя/продукта (VID/PID) и ассоциированных COM-портов. 

### 🧩 Ключевые возможности (Features)

* **🔍 Автоматический поиск USB-устройств:** 

  * Сканирование активных шин с помощью WMI/CIM-командлета Get-CimInstance Win32_DiskDrive с фильтрацией по типу интерфейса "USB".
  * Извлечение «чистых» серийных номеров накопителей с автоматическим удалением системных пробелов и служебных символов.
* **🔎 Глубокий аудит реестра Windows:** 

  * Поиск связей VID и PID в ветке реестра HKLM:\SYSTEM\CurrentControlSet\Enum\USB.
  * Рекурсивное сканирование вложенных параметров и ключей контроллеров (включая проверку GUID-идентификаторов портов) для точной идентификации устройства.
  * Резервный механизм поиска символических имен устройств через ветку Enum\USBSTOR, если данные отсутствуют в стандартных разделах.
* **💾 Интерактивный экспорт в CSV (GUI-диалог):** 

  * Использование графических компонентов .NET Windows Forms (SaveFileDialog) для удобного выбора пути сохранения отчета.
  * Автоматическая генерация имени файла экспорта по маске: USB_rep_Дата_Время.csv.
  * Потоковая запись результатов сканирования с принудительным использованием кодировки UTF-8 для предотвращения проблем с отображением кириллицы.
* **📊 Структурированный консольный вывод:** 

  * Форматированный текстовый вывод ключевых параметров каждого устройства (Серийный номер, VID/PID, статус порта) с использованием цветового кодирования (Write-Host).
  * Корректная обработка исключений при отсутствии прав или отсутствии подключенных USB-устройств.

### 🛠️ Стек технологий (Tech Stack)

* **Язык:** PowerShell 5.1+ / PowerShell 7+
* **Интерфейс:** .NET Framework (System.Windows.Forms).
* **Компоненты ядра:** Работа с реестром (Get-ChildItem), системные службы CIM (Win32_DiskDrive).
* **Платформа:** Windows 10 / 11, Windows Server.

### 🚀 Инструкция по запуску

Для чтения низкоуровневых параметров некоторых USB-контроллеров и защищенных веток реестра скрипт рекомендуется запускать **от имени Администратора**. 

1. Откройте PowerShell от имени Администратора.
2. Перед первым запуском (если в системе заблокировано выполнение скриптов) выполните:

powershell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

Используйте код с осторожностью.

3. Запустите скрипт анализа:

powershell

.\usbserial.ps1

Используйте код с осторожностью.

4. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.

5. Скрипт начнет сканирование. Если устройства будут найдены, откроется графическое окно проводника с предложением сохранить итоговый CSV-отчет. По завершении нажмите любую клавишу для выхода.
