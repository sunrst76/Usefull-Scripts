# 🚀 Менеджер автозагрузки Windows (Autostart.ps1)

Скрипт автоматизации на языке **PowerShell**, предназначенный для сканирования, структурированного вывода и интерактивного удаления элементов автозагрузки Windows из реестра и системных каталогов.

## ✨ Ключевые возможности (Features)

* 🔍 **Комплексный аудит автозагрузки**:
  * Сканирует ключевые ветки реестра: `HKLM:\...\Run`, `HKLM:\...\RunOnce`, `HKCU:\...\Run`, `HKCU:\...\RunOnce`, а также 32-битные записи в 64-битных системах (`Wow6432Node`).
  * Проверяет физическую папку «Автозагрузка» в профиле пользователя (`AppData\...\Programs\Startup`).
* 🖥️ **Win32 API Интеграция**: использует функции `user32.dll` для автоматического вывода окна консоли PowerShell на передний план при запуске.
* 📊 **Удобный вывод данных**: динамически формирует массив объектов со сквозной нумерацией `[ID]` и отсеивает системные свойства PowerShell для чистоты отчета.
* 🗑️ **Безопасное интерактивное удаление**:
  * Позволяет выбрать элемент по его ID и удалить его одной командой.
  * Автоматически определяет тип элемента (удаляет параметр из реестра или ярлык `.lnk` из папки).
  * Содержит обработку ошибок (например, при нехватке прав Администратора).
* ↩️ **Выход без изменений**: если вместо ID нажать `Enter`, скрипт завершит работу без изменения системы.

## 🛠️ Стек технологий (Tech Stack)

* **Язык**: PowerShell 5.1+ / PowerShell 7+
* **Технологии**: Win32 API (P/Invoke через `Add-Type`), Работа с системным реестром Windows.
* **ОС**: Windows 10 / 11.

## 🚀 Инструкция по запуску

### Важно: Права доступа
Для удаления записей из системных веток реестра (`HKLM`) скрипт необходимо запускать в консоли PowerShell, открытой **от имени Администратора**.

1. Откройте терминал в папке со скриптом.
2. Перед первым запуском (если в системе заблокированы скрипты) выполните команду:
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
   ```
3. Запустите менеджер:
   ```powershell
   .\autostart.ps1
   ```
или запустите с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.
