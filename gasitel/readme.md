# ☕ Скрипт предотвращения спящего режима (Gasitel.ps1)

Легковесный фоновый скрипт на языке **PowerShell**, предназначенный для имитации активности пользователя. Утилита предотвращает блокировку экрана Windows, засыпание компьютера и автоматическую смену статуса в корпоративных мессенджерах на «Отсутствует».

## ✨ Ключевые возможности (Features)

* 🛡️ **Симуляция активности без перехвата ввода**: каждые 180 секунд (3 минуты) скрипт программно эмулирует нажатие клавиши Scroll Lock. Эта клавиша выбрана потому, что её нажатие абсолютно незаметно для пользователя, не мешает текущей работе и не вводит ложные символы в открытые документы.

* ⏳ **Настраиваемый таймер работы**: принимает входной параметр $minutes (по умолчанию равен 1200 минутам / 20 часам), определяющий, как долго скрипт будет поддерживать систему в активном состоянии.

* 🪶 **Минимальное потребление ресурсов**: использует стандартный COM-объект WScript.Shell, практически не нагружает процессор и оперативную память во время ожидания.

## 🛠️ Стек технологий (Tech Stack)

* **Язык**: PowerShell 5.1+ / PowerShell 7+

* **Инструменты**: COM-интерфейс Windows Script Host (WScript.Shell), метод SendKeys.

* **Платформа**: Windows 10 / 11.

## 🚀 Инструкция по запуску

Скрипт работает в обычном пользовательском контексте и не требует прав Администратора.

1. Откройте терминал в папке проекта.

2. Запустите скрипт со стандартным временем работы (20 часов):

```powershell

.\Gasitel.ps1

```

3. **(Опционально)** Если вы хотите задать своё время работы (например, поддерживать активность ровно 2 часа / 120 минут), укажите параметр при запуске:

```powershell

.\Gasitel.ps1 -minutes 120

```

4. Для остановки работы скрипта просто закройте окно консоли или нажмите сочетание клавиш Ctrl + C.

```

5. Можно запустить скрипт с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.

```

6. Также можно ярлык поместить в автозагрузку пользователя. Для этого:

```

в свойствах ярлыка укажите:

C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\ваш_путь\Gasitel.ps1""

```

поместите ярлык в автозагрузку текущего пользователя:

```

нажмите Win+R, в открывшемся окне введите shell:startup и нажмите Enter

```

скопируйте ярлык скрипта в открывшуюся папку и перезагрузите компьютер

```
