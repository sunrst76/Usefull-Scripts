## 🚀 Требования и особенности запуска

### 🟦 1. Скрипты PowerShell (`.ps1`)
Разработаны для запуска в ОС Windows 10 / 11 через оболочку **PowerShell**.

⚠️ **Важно:** По умолчанию Windows блокирует запуск сторонних скриптов. Перед первым использованием откройте PowerShell от имени Администратора и разрешите выполнение скриптов текущему пользователю:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Пример запуска скрипта:**
```powershell
.\Backup-Tools.ps1

или запустите с помощью приложенного ярлыка, в свойствах которого укажите ВАШ путь к скрипту.

```
---
### 🟩 2. Скрипты Bash (`.sh`)
Предназначены для запуска в UNIX-подобных системах (Linux, macOS, WSL в Windows).

⚠️ **Важно:** Перед запуском скрипту необходимо выдать права на исполнение.
```bash
chmod +x deploy-service.sh
```

**Пример запуска скрипта:**
```bash
./deploy-service.sh
```
